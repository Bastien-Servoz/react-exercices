# react-exercices

Exercices et notes de cours React et Redux — Formation Epitech Pré-MSc, cours "From Scratch" (HTML/CSS/JS/React).

**Auteur :** Bastien Servoz ([@Bastien-Servoz](https://github.com/Bastien-Servoz))

## Objectif

Ce dépôt regroupe le travail réalisé pendant la partie bonus du cours : React (2 cours) et Redux (2 cours), code écrit en live avec le formateur.

Il fait suite aux dépôts précédents :

| Dépôt                | Contenu                                                                     |
| -------------------- | --------------------------------------------------------------------------- |
| `html-css-exercices` | HTML/CSS, TD 1-3                                                            |
| `seo-sass-exercices` | SEO (robots.txt, seo.txt, html-helium) et Sass (variables, mixins, @import) |
| `js-exercices`       | JavaScript : bases, DOM, data, API, objets, canvas, tests                   |

L'historique détaillé est conservé dans [`JOURNAL.md`](./JOURNAL.md).

## Structure du dépôt

```
react-exercices/
├── README.md
├── JOURNAL.md
└── .gitignore
```

Le schéma sera complété au fil des cours.

## Conventions

- Noms de fichiers et dossiers **en minuscules, sans espaces**
- Un dossier par partie de cours, un sous-dossier par projet
- `node_modules/` jamais versionné (voir `.gitignore`)
